# QuickNotes

Локальная база заметок для Windows: быстрое сохранение выделенного текста, Markdown, теги, полнотекстовый поиск, история изменений и вложения.

*A local-first Windows notes app with Markdown, tags, search, history, and optional encrypted cloud sync. Russian interface.*

**Дорелизная версия.** Приложение активно развивается; полноценный релиз 0.9 ещё не подтверждён всеми проверками. Реальная приёмка S3, восстановление на отдельной учётной записи Windows и полная визуальная матрица остаются отдельными задачами. Начните с тестовых заметок и сохраняйте независимые резервные копии важных данных.

## Возможности

- Захват текста из других приложений, заметки с тегами и Markdown.
- Поиск на SQLite FTS5 и структурные операторы.
- История заметок, вложения, шаблоны, задачи и напоминания.
- Рабочее пространство со списком, редактором и карточной доской.
- Защита заметок паролем и зашифрованные архивы с механизмом восстановления.
- Опциональная синхронизация через S3-совместимое хранилище и обработка конфликтов.

Для локальной работы облачный аккаунт не требуется. Интерфейс рассчитан на Windows и преимущественно на русский язык.

## Запуск из исходников

Нужны Windows 10/11 и [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0). Откройте PowerShell в корне скачанного или клонированного репозитория:

```powershell
dotnet restore QuickNotes.sln
dotnet build QuickNotes.sln -c Release --no-restore -warnaserror
dotnet run --project QuickNotes.App -c Release --no-build
```

Первый запуск создаёт локальный профиль в `%LOCALAPPDATA%\QuickNotes`. Не используйте основной профиль для экспериментов с миграциями, синхронизацией и восстановлением архивов. Изолированные проверки описаны в [руководстве разработчика](docs/development.md).

## Данные и облачная синхронизация

Заметки хранятся локально. Ключи S3 защищаются Windows DPAPI и хранятся отдельно от базы заметок. Облачная синхронизация включается отдельно и требует собственного хранилища.

**Поддержка S3 пока не означает подтверждённую совместимость со всеми провайдерами.** Для первых проверок используйте отдельный тестовый бакет. Обычные тесты не подключаются к реальному S3 без явного opt-in; успешный CI сам по себе не подтверждает облачную приёмку.

Зашифрованный архив `.qnar` можно восстановить через CLI с передачей пароля или recovery key через stdin. Восстанавливайте его в новый или пустой каталог. Не публикуйте базы заметок, архивы, настройки с личными путями, облачные ключи и результаты живых проверок. Подробности восстановления и его ограничений — в [руководстве](docs/development.md).

## Разработка и проверки

```powershell
dotnet restore QuickNotes.sln
dotnet format whitespace QuickNotes.sln --verify-no-changes --no-restore
dotnet build QuickNotes.sln -c Release --no-restore -warnaserror
dotnet test QuickNotes.sln -c Release --no-build --no-restore --nologo --blame-hang --blame-hang-timeout 2m
```

[CI](.github/workflows/ci.yml) выполняет проверку форматирования, сборку с предупреждениями как ошибками и полный набор тестов. После успешного задания тестирования отдельное задание собирает переносимый архив Windows x64 с .NET runtime. Архив доступен в артефактах соответствующего запуска Actions; GUI и облачная приёмка этим не подтверждаются.

[Облачная приёмка](.github/workflows/cloud-acceptance.yml) запускается только вручную и требует настроенного окружения `cloud-acceptance`. Для неё не нужны секреты в исходном коде или в обычном CI.

Локальная сборка переносимой версии:

```powershell
dotnet publish QuickNotes.App/QuickNotes.App.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=false -p:PublishTrimmed=false -o artifacts/portable/QuickNotes
```

Запускайте `QuickNotes.App.exe` из полученного каталога вместе с остальными файлами. Переносимой здесь является сборка: профиль по умолчанию по-прежнему хранится в `%LOCALAPPDATA%\QuickNotes`.
