# ADR-009: сборка быстрых заметок в одну Markdown-заметку

- Дата: 2026-09-12
- Статус: Accepted
- Реализовано в коде: да для Release 1.2 §8.2
- Пересмотр: при запросе на копирование вложений или сборку защищённых заметок в новый защищённый конверт
- Связанные документы: [VISION.md](../../VISION.md), [ROADMAP.md](../../ROADMAP.md), [001-markdown-product-boundary.md](001-markdown-product-boundary.md)

## Контекст

ROADMAP §8.2 требует операцию «Собрать заметки»: пользователь задаёт порядок исходников, разделитель, итоговый заголовок и судьбу исходников; до commit виден полный preview; по умолчанию исходники сохраняются.

## Решение

- **Уже в коде.** `NoteAssemblyService` строит детерминированный Markdown (`# заголовок`, нормализованные `\n` тела, разделитель) и `PlanHash` (исходники + канонический TagId/Origin/имя) без записи. Commit — `ILocalMutationCoordinator.ExecuteBulkMutation`, внутри него revalidation и одна SQLite-транзакция: новая незащищённая заметка, union существующих неподавленных тегов (Manual побеждает Auto, новые теги не создаются), начальная ревизия, опционально `DeletedAt` исходников. Расхождение тегов или snapshot после preview отклоняет запись. Sync/reload только после успешного commit. Повтор всегда создаёт новую заметку; одинаковые заголовки допустимы. Предпросмотр и commit блокируются для любого `IsProtected` исходника без чтения session plaintext.
- **Принятое направление.** Разделители: пустая строка, `---`, `***`, однострочный custom. Минимум два исходника; дубликаты id, пустой набор, корзина и расхождение snapshot после preview запрещены. Вложения не копируются: Markdown-ссылки остаются текстом. Сборка не является inbox-захватом и не запускает автотеги по объединённому тексту. Каталог кандидатов — страница 50 + поиск/«Ещё», без `ToList()` всего архива; защищённые не ищутся по plaintext.
- **Не является решением.** Сборка в защищённый конверт, WebView2-preview, слияние в существующую заметку, отдельная сущность Task.

## Альтернативы

- Тихое объединение с существующей заметкой того же заголовка — отвергнуто ROADMAP.
- Показ plaintext разблокированной защищённой заметки в preview — отвергнуто: результат был бы незащищённой копией в SQLite/FTS.
- Автодетект тегов по собранному тексту — отвергнуто как создание неожиданных тегов.

## Последствия

Новой схемы БД нет. UI: `NoteAssemblyWindow` / `NoteAssemblyViewModel`, пункт «Собрать заметки…». Тесты: `NoteAssemblyServiceTests`, `NoteAssemblyUiTests`, `NoteAssemblySmokeTests`. CLI: `--quick-note-assembly-smoke`.
