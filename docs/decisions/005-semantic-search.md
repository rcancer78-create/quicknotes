# ADR-005: семантический поиск — комплектовать или удалить

- Дата: 2026-09-10
- Статус: Accepted / Implemented
- Реализовано в коде: направление B — подсистема удалена; production search path — FTS5 и структурный поиск
- Пересмотр: не требуется до отдельного нового ADR
- Связанные документы: [ROADMAP.md](../../ROADMAP.md)

## Контекст

`ROADMAP.md` §10.1 запрещал оставить «полностью обслуживаемую функцию, которую пользователь должен вручную оживлять внешним файлом».

До закрытия ADR код был устроен именно так: отдельный индекс, настройки модели, UI и отсутствие bundled-модели. Лицензирование, размер и обновление модели не были определены. Внешний пользовательский `.bin` / `.vec` / `.txt` запрещён как release-состояние.

## Решение

- **Уже в коде.** Смысловой поиск удалён: нет сервисов, отдельной SQLite-базы индекса, настроек, UI-секции, toggle/badges и веток в `SearchService`. Поиск — FTS5 плюс структурные операторы и in-memory hits разблокированных защищённых заметок. Пагинация и `COUNT(*)` остаются на стороне базы.
- **Принятое направление.** Вариант B: полное удаление. Вариант A (компактная лицензированная модель в поставке) отвергнут: артефакта модели нет, лицензия/размер/обновление не определены.
- **Эксперимент.** Ручное подкладывание файла модели больше не поддерживается.

Старые поля `settings.json` (`SemanticSearchEnabled`, путь модели, порог, кандидаты) игнорируются при загрузке и не записываются обратно. При старте best-effort удаляется только известный файл `%LocalAppData%\QuickNotes\semantic_index.db` и его SQLite sidecars `-wal`/`-shm` в корне профиля; `quicknotes.db`, backup и прочие файлы не трогаются. Каталог `Models` и вложенные копии индекса автоматически не чистятся.

## Альтернативы

- Поставить модель без лицензии/размера/обновления — преждевременно.
- Оставить opt-in внешний файл — запрещено §10.1 как release-состояние.

## Последствия

Пользовательские заметки, FTS, защита, черновики, sync и reminders не меняются. Смысловой режим в строке поиска больше не обещается. Повторно вводить смысловой поиск можно только новым ADR с bundled-моделью.
