# Импорт из Word, HTML и Markdown

QuickNotes хранит только Markdown/plain text. HTML не становится вторым форматом документа. Word и OneNote напрямую не разбираются.

## Word → HTML или Markdown

1. В Microsoft Word откройте документ.
2. **Файл → Сохранить как**.
3. Выберите **Веб-страница с фильтром (*.htm; *.html)** или экспортируйте в Markdown сторонним конвертером.
4. Сохраните связанные изображения в ту же папку (относительные пути).
5. В QuickNotes: **Импорт и экспорт → Выбрать папку…** и укажите каталог с HTML/Markdown.

Фильтрованный HTML Word обычно содержит лишние `span`/`o:p` и стили. Стили, скрипты, iframe и внешние картинки отбрасываются. Текст, заголовки, списки, таблицы и локальные изображения по возможности превращаются в Markdown.

## OneNote

Внутренний формат OneNote не импортируется. Экспортируйте страницы в HTML или Markdown, затем импортируйте как выше.

## Что сохраняется

- Заголовки, абзацы, переводы строк
- Emphasis/strong, `code`/`pre`
- Нумерованные и маркированные списки, checkbox если они есть во входном HTML
- Ссылки на локальные файлы и `mailto:`
- Таблицы (pipe Markdown)
- Цитаты
- Локальные изображения как вложения + Markdown `![]()`

## Известные потери

- CSS, темы Word, SmartArt, ActiveX, макросы
- `script` / `style` / `iframe` / `object`
- Внешние URL картинок, `data:` URI, `javascript:`
- Глубокая вложенность папок глубже «блокнот / раздел» не сглаживается молча
- Сложные вложенные таблицы могут упроститься

Перед commit показывается предпросмотр потерь. Блокирующие ошибки (обход пути, reparse, лимиты) отключают импорт. Неблокирующие потери требуют явной галочки подтверждения.

## Повтор

Повтор того же файла (тот же относительный путь и то же содержимое) не создаёт дубликат; изменение только даты файла не меняет отпечаток. Совпадение только заголовка не сливает разные заметки; можно явно пропустить, импортировать отдельно или заменить, если совпал тот же источник и заметка не защищена. Word/OneNote и прочие неподдерживаемые файлы в дереве показываются в диагностике и требуют подтверждения потерь.
